# Exact native receipt container in Lean (candidate)

T044/T048/T049/T053/T057/T060; amendment 0001. NO_GO.

NativeReceiptBytes.lean implements the actual DVREC001 binary container using
List UInt8: exact 16-byte version/reserved header, big-endian action and sequence,
four zero operational/reserved bytes, three uint32 length-prefixed sections and
complete input consumption. The complete original DRC1 vote frame is retained
as opaque bytes. No proposal JSON receipt is treated as native binary evidence.

The general proofs establish big-endian decoding for every width and bounded
natural number, length-prefix inversion, complete receipt roundtrip, encoding
injectivity on structurally valid receipts, exact field retention, canonical
accepted bytes and preservation when operational replay changes. The proofs do
not assume encoding injectivity or receipt equality; injectivity follows by
applying the independently implemented reader and the proved roundtrip.

Structural guards retain action1..9, positive uint64 sequence, printable ASCII,
16MiB receipt / (16MiB-8KiB) frame, 71-byte ID and 4096-byte context bounds. The
size theorem derives the exact 44+frame+ID+context length and transport ceiling.
A final re-encoding check provides fail-closed canonicality. General roundtrip
proves that this extra check accepts every structurally valid encoded record.
There is no claim about native allocation strategy, execution complexity or
all general-purpose DRC1 parser limits.

## Explicit semantic boundary

The module is a STRUCTURAL CONTAINER codec, not the complete native semantic
receipt parser. It does not yet parse DRC1 frame fields, compute SHA-256, establish
ID/frame or action/context/sequence/frame equality, or prove vote admission.
The separately executable native parser performs those extra checks. The Lean
countercheck structuralDoesNotAuthenticate accepts a deliberately unauthenticated
but well-shaped container. Thus neither decode success nor these proofs may be
used as an authority/authentication or full native-parser-equivalence predicate.

No native policy producer, policy-to-WAL relation, physical scan, public state,
certificate, current pointer, unknown durability or public/native recovery
relation is inferred from receipt structural validity. The next adapter must
bind the exact DRC1 fields and native domain-separated vote-ID preimage before
composing the receipt with original policy/WAL records and reachable history.
Collision/hash, source provenance and native parser compatibility obligations
must remain explicit. nativeArithmeticRecoveryRefines stays missing.

## Native execution and kernel examples

Nine unchanged PR50 translation units from
60c692f6e391f839829dfc64e93380db54cd507b execute the operational receipt encoder
and parser. All nine original vote fixtures are encoded with replay=false/true;
the native output is identical. Twenty-seven native negative checks cover a
nonzero reserved replay byte, trailing bytes and a changed content ID. In the
last case the container remains structurally valid but the native parser rejects
its false ID-to-frame claim. No runtime/WAL, network or arithmetic admission is
executed in this codec run. In particular PARAMETER/APPLY codec examples do not
bypass their native admission guard. The prior actual runtime/WAL runs remain
separate unchanged evidence.

The generated NativeReceiptVectors.lean retains every exact original frame and
native receipt byte. Nine full encoding identities use compositional byte
segments, and decode/retry examples use the general inverse theorem; no giant
combined state reduction or native_decide is used. Reserved-byte negatives use
a general prefix-rejection theorem. Small examples cover zero sequence, invalid
action, nonprintable text, truncated/over-limit sections, UINT64 maximum and the
explicit unauthenticated-container countercheck. All named definitions/theorems
are in the mandatory import and axiom audit.

Run generate_native_receipt_vectors.py with --vcvars pointing to VS2019
vcvars64.bat to compile the unchanged codec and reproduce its bytes. Without
--vcvars it regenerates the Lean/vector documents from validated pinned native
observations. Six tooling tests verify exact original frames, output mutation
rejection, source pins, generated byte reproduction and audit coverage.
