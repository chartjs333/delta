## General composition and domain

`FamilyInputs.prepareOriginalVector` decodes the actual original plan,
accumulator and available manifests without the draft adapter's participant
cap. Complete ISC/EC rows and exact APC weights/buckets remain checked. The
original native decoder, manifest and coefficient limits are retained. The
previous general family and ordered reconstruction for original widths
4/8/8/8/8 and starts 0/4/12/20/28 are reused; no proof per length is required.

`originalConfiguredInputTotal` derives the selected image and every numerical
input guard from that corpus and `OriginalNumericConfiguration`.
`loadOriginalNumericConfiguration` selects the profile from the same original
policy and checks normalization, original accumulator ID, current/schema/parent
links and dimensions. Quantum is read through the existing `UnitSource` key
(context/APC/profile/accumulator/current), not inferred from integer values or
invented. Its authentication remains the existing named primitive boundary.
`FamilyAuthority.originalConfiguredInputLoaded` composes this with the full
executable encoder. `originalAuthorityLoaded` and the component canonicality
proofs construct authority and original ISC/seed/EC/APC parents.

OMIT_UNAVAILABLE completion preserves the entire configured input namespace.
Unavailable/unobserved inputs have a latent 0/1 weight and zero Q representative;
`completionSelectedRowsExact` and `completedImageComputesSameRows` prove those
representatives never enter the actual eligible PARAMETER computation. This is
an abstract completion, **not a claim that unavailable native bytes are zero**.
No committed ISC member, original EC decision or native artifact is removed.

`FamilyParameter.originalVectorTotal` derives every full PARAMETER vector from
the original manifest rows. `originalParameterProjectionTotal` derives scalar
acceptance from the original coefficient proof and selected image, preserving
the entire native vector/leaves and parents. `originalParameterResultGuard`
proves the exact scalar sum and symmetric bound including the signed minimum.
The constructor checks the native full-vector equality before exposing any
coordinate. `originalValueFromOwnInputs` connects the result to its own complete
input image. Primitive domain/shard aliases remain explicitly checked.

`FamilyApply` retains the exact full ordered native aggregate corpus. ROOT does
not require future conversion or APPLY success. The APPLY path checks every
original conversion, unique complete global coordinate placement and the
original normalized profile's domain order. `originalConversionPublicGuards`
retains all conversion products and denominators. `originalApplyCoordinatePublicGuards`
retains mixture first/scaled products, every prefix and all optimizer
intermediates, including zero learning rate. `originalCoordinateComputesNextCells`
connects the same global source offset to current and next scalar tables.
`originalApplyCheckedFromConstructed` derives whole-candidate acceptance and
canonicality from constructed components, not a supplied body translation.

The coefficient common denominator and optimizer fraction denominators may use
the full original uint64 domain. A PARAMETER success alone does not imply a
later conversion succeeds. Conversion arithmetic uses the declared original
accumulator width; unsafe intermediate products are rejected. The native final
mixture LCM must fit int64, which justifies the existing mixture denominator
and prefix checks. Raw profile syntax alone does not imply normalization;
normalization is checked on the exact selected immutable profile as already
required by the arithmetic amendment and ABInputsValid.

Names are mapped through checked primitive namespaces. Actual native labels
round-trip byte-exactly before lookup, including quotes/backslashes, and are
not required to satisfy the old draft identifier grammar. Public aliases must
still be canonical and injective on their configured namespace. A coordinate
is a representation index, never a new shard, vote, signer, certificate or WAL
slot. Missing/ambiguous native shard aliases reject.

## Remaining static relation (obligation 3 only)

`FamilyRelation.Direct.loadStoredProjection` is the executable arithmetic
entry point for a stored WAL record. It reads the original vector source, same
policy and committee, selected immutable profile and source-keyed quantum.
It decodes the original WAL record and selects the original candidate from the complete
native snapshot. The full PARAMETER/APPLY constructor computes the public body;
its context is derived from that body. Primitive names and canonicality are
checked, and an altered supplied vote is rejected. All coordinate views keep
the same original body ID, signer and WAL sequence. Input ticket order/names
are proved equal to the actual APC member order/names, not only their count.

The deterministic receipt is derived from the original command/candidate/hash;
it need not have been observed or exposed. Any supplied observed receipt must
match exactly. This does not imply response exposure, network delivery or quorum
power. `loadLocatedProjection` checks the complete original mixed WAL byte
partition and the original position, including intervening command records.
All coordinate views preserve the original per-actor sequence and object.
UNKNOWN, corrupt scans and incomplete/torn observations reject this complete
source path. The whole original stream is retained; the collection join below
also checks complete public vote coverage for the supported per-record constructors.

`loadObservedProjection` reuses the existing nonempty pointer-history reader.
Original candidate value preimages determine current model/optimizer hashes;
UNKNOWN rejects. The pure constructor's `CurrentBasis` now holds values,
pointer and schema independently of a preceding APPLY carrier. Existing history
unit keys and links are definitionally unchanged. `loadAnchoredProjection`
checks canonical current-value spellings and both original hashes against an
anchor with explicit existing `anchorAuthenticated/recoveryAuthenticated`
premises, then checks source context/schema and pointer optimizer identity.
This represents initial numeric values without inventing an APPLY. It does
not establish the complete initial snapshot or pointer-QC relation; those stay
in 3. No new recovery-preservation theorem is claimed. The original native
arithmetic guard still rejects; this is not production admission/execution.

`loadCertifiedCurrent` adds the static non-genesis case: it decodes the original
policy/state and complete APPLY section, finds the exact pointer QC in the
original finalized list, checks model/optimizer/height and reads the original
canonical vector preimages. `loadSnapshotProjection` feeds these same values
into the direct input/body constructor and checks the next source parent.
Missing or unfinalized QCs cannot supply this witness. Every coordinate selector
retains that original QC and current vectors. This is neither replay nor an
assertion that a decoded source is authenticated. Initial states with no prior
QC keep the separate anchor path; no fictitious APPLY is introduced.

`loadCurrentField` checks the actual public currentCheckpoint field against the
same pointer through both existing checkpoint namespaces. Joined to
`loadSnapshotProjection`, it binds that public symbol to the original finalized
QC and both computed native vector hashes. Initial checkpoint names are not
silently identified with model hashes. The original current certificate's actual
signer quorum is preserved through the same decoded policy and actor namespace;
coordinate projections add no signers.

`loadCurrentCertificateParents` constructs complete ISC/seed/EC/APC ancestors
directly from the original current QC's native parent graph. It reads height,
epoch and config from the actual ISC context and reuses the original primitive
metadata, entry/member lists and parent checks. It needs no local vote for a
certificate received from another validator. The resulting parent values are
proved equal to the existing vote-based constructor at the same original
context, and the selected APC is proved a member of the original checked
snapshot. Its height/epoch/config are derived through the actual native parent
checks; agreement with a vote loaded from the same original bytes needs no
supplied public-body or control equality. The complete remote certificate/body/collection join remains open;
this removes the local-vote dependency for these parent values only.

`loadRootProjection` uses the same direct numeric source and original native
ROOT selector. Every original finalized PARAMETER certificate is retained in
the original ordered corpus; its native body ID and parent context come from
`NativeRootSource`. The complete family aggregate is wrapped by the existing
`PublicRootEnvelope.envelope`: kind AGGREGATE_ROOT, context equal to its complete
APC. It does not call the arithmetic-only `PublicState.expectedContext`.
Primitive namespaces, original actor and WAL position are checked, and selector
views cannot inflate signers or create new native objects. ROOT construction
does not require a future APPLY or successful conversion/optimizer computation.

The shared-parent lemmas derive full ISC, seed, EC and APC equality between
ROOT and arithmetic observations, and between selectors, from the same native
objects and primitive metadata functions. Whole public-parent equality is not
supplied as a premise. Different votes keep their original actor identities.

`loadVoteCollection` reads the whole known, non-torn mixed WAL and constructs
each vote using direct PARAMETER/ROOT/APPLY or the existing CONFIG/ISC/EC/APC/
VIEW/ABORT projectors. Source packets contain original per-record artifacts,
facts and current inputs; they contain no supplied public body. The computed
vote list must be duplicate-free and exactly match the supplied public set.
General proofs reject dropped, added or substituted votes, retain source packet
order and every physical WAL sequence, and preserve canonical public values and
original actors. Commands stay in the original byte partition and position
space, while the public logical vote count excludes commands. Receipt
construction does not imply response exposure or message delivery.

`loadDurableVoteState` checks the exact original actor inventory and applies
that collection check to every actor's slice of the existing full public
durableVotes field. It proves both public-to-native and native-to-public
coverage and checks durableSequence against the original vote count. A missing
actor, UNKNOWN stream, duplicate public vote or unconstructible payload cannot
be replaced by an empty collection. This is a general checked static component;
total applicability across admissible snapshots and provenance of the complete
observations are still part of 3, not results of the byte scan alone.

Within that whole observed inventory, `ConfigNamesSeparated` rejects distinct
native config IDs mapped to the same public config name. Forward equality is
derived from the shared source naming function. This is a check on actual
observed records; it neither assumes injectivity between unrelated namespaces
nor authenticates an unobserved configuration.

`loadObservedState` now joins these existing components in one executable static
check: the complete all-actor durable vote field, actual certified current,
currentCheckpoint field, original policy/actor namespace and current certificate
parents. It checks the forward configuration name through the same primitive
source used by the journal and inverse separation across the current policy plus
every observed journal record. Thus the current checkpoint and a historical vote
cannot use the same public config name for different native config IDs; equal
native IDs have the same public name. Current QC signers still use the original
policy. This is a partial static relation, not coverage of the remaining state
fields or proof of applicability to every initial/incomplete snapshot.

The existing failure constructor is reused unchanged: VIEW limits and deadlines
are checked; its ABORT branch currently constructs only original empty-downstream
lineage and rejects nonempty lineage. This is a recorded applicability limit of
this component, **not a new requirement for a universal full ABORT body gate**.
The frozen sufficient ABORT projection must be joined at the remaining relation
boundary. No certificate/terminal/current semantics is inferred from an opaque
authorization flag.

The outstanding interfaces are finite and unchanged: one original-source
configuration and alias namespace; total applicability of the existing kind
projections; exact remaining certificate/candidate/current/environment collection
coverage in the same 64 PublicState fields. The durable vote/sequence component
above does not establish the other fields or the existing complete-document
depth/node/byte guards. Those are the existing state representation checks,
not extra native arithmetic preconditions or new requirements. This includes current, availability,
unobserved or incomplete evidence, and the corresponding certificate collections.
A native ROUND_STATE summary is not a full public state. No unknown collection
may be silently replaced by an empty one, and otherAuthorized is not a phase
or QC proof. ABORT needs the frozen sufficient projection; no universal full
ABORT-body gate is added. Transition/recovery preservation belongs to R3 and
is excluded from this stage.

The existing configured ExpectedNextCheckpoint is mapped to the exact native
computed next-model hash. Its source/configuration/alias coherence remains in
3. No new checkpoint ID is invented; structured TLA vector values are not
native cryptographic content IDs.

Original004 vector artifacts have no joined original vector vote/QC/WAL capture.
No scalar original008 identities or fabricated protocol objects are spliced in.
The mathematical original-optimizer graph is source-reviewed, not a C++
execution/compiler verification. Hash, codec, metadata, certificate and source
authentication remain named boundaries; self-review is not independent review.
R2 must connect the named FR-033 witnesses consistently to the exact original
source/body/context; this does not add a production exporter project or move
R7's independent attestation into the local R2 scope.
