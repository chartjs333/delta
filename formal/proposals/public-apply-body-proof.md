# Complete computed aggregate/APPLY body with model-width rechecks

Tasks T044/T048/T049/T053/T057/T060; Feature000 amendment 0001. This is conditional
body construction and known-cut journal composition, not full public admission,
native execution, recovery refinement or Formal GO. The remaining mandatory
nativeArithmeticRecoveryRefines conjunct is not discharged.

PublicApplyArithmetic rechecks every actual ConvertedParameter from the native
certified corpus at the projected model bounds. Equality with each native
converted vector follows from the exact conversion formula, including rounding
within each domain. The list relation retains every original converted entry;
native convertedSources ties that list to the complete certified PARAMETER list.
No command supplies a converted vector or expected numerical equality. The
checked conversion trace retains separate numerator and denominator products.

APPLY is recomputed at the model width using the actual NativeApply rows,
independently bound current model/optimizer and profile coefficients. A general
cross-width theorem derives denominator, gradient, next model and next optimizer
identity from checked LCM, mixture and optimizer traces. Its inputs are the same
native-derived rows, rather than caller-selected mathematical replacements.
Separate first/scaled mixture products, ordered prefixes and all twelve native
optimizer intermediates are checked even with zero learning rate. No wide
success is silently treated as narrow success. Extra kernel restrictions on
fraction/LCM/denominator ranges remain projection restrictions, not native
admission changes or an equivalence theorem for production TLA guards.

PublicApplyBody iterates the actual certified.corpus.entries. Every original
DerivedParameter produces a complete PublicParameterBody projection with the
same source-bound input corpus and PublicAuthority. Checked frame equality,
exact rows and all original native parameter checks are retained. General
lemmas preserve ordered leaf count and position, complete original source,
authority and parents. The certified original native aggregate payload is the
full ordered native body list, under its existing anchor/certificate premise.
The public aggregate contains all twelve fields. Its leaves and canonicalRoot
are the same canonical set; sorting retains values and final canonicality
rejects duplicates, rather than dropping them.

The complete ten-field APPLY value includes that entire aggregate, authority,
round/config, parent, apply profile, next checkpoint and schema-tagged next
model/optimizer tables. Table coordinates come from the actual native result
and the same checked scalar schema. Whole-candidate equality and canonicality
reject omitted/substituted/extra body fields. Structured public NativeModelHash
values are not treated as native cryptographic content IDs.

Checkpoint identity requires special care. Native APPLY_EXPECTED has next
model/optimizer hashes but no independent nextCheckpoint field. Read-only
existing C++ evidence in CurrentPointerStore::advance checks
command.next_checkpoint_id == apply_qc.next_model_hash. The public TLA body
instead compares its symbol with configured ExpectedNextCheckpoint. This layer
takes that primitive symbol separately from the candidate, requires a model
value, and checks that the independent IdentityMap maps it to the exact canonical
sha256 spelling of the computed native next model hash. It does not invent a
checkpoint name or derive one from an opaque public label.

The existing runtime convention is evidence, not a newly frozen formal contract.
Independent configuration provenance, the map's authentication/injectivity and
the full ApplyQC/CurrentPointerCommand edge are still required. NativeReplay's
existing applyAuthenticated premise is not discharged here. No public current
advance is authorized by this constructor alone. The fixture map is synthetic;
its original byte spelling is checked against the pinned native result.

PublicApplyJoin uses the old complete PARAMETER loader for PARAMETER and the new
complete APPLY loader for APPLY. Both bind actual original NativePrepared
records, all-field PublicVoteEffects, native current/frame/time and original
sequence, then compose successful PublicRecovery.persist with reachable journal
operations. UNKNOWN still rejects at this complete-state API. This composition
does not match the entire preceding public durable set to the journal: only the
inherited count check is present. Global send/delivery/quorum eligibility,
non-arithmetic phase admission, configuration/alias consistency, complete current
advance and public/native crash/unknown recovery remain open. Unknown or
incomplete scans do not become evidence of absence; existing exact authenticated
presence/absence and blocked-scan rules remain necessary.
