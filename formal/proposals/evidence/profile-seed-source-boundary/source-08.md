## Authority rule

C++ alone verifies and advances the certificate graph, derives robust decisions, assembles exact
coverage, computes apply artifacts, emits votes/effects and chooses current state. Java authenticates
and transports opaque bytes, delivers opaque timers and executes bounded artifact effects. Python
trains against finalized tickets. Neither Java nor Python may infer, repair or override native
quorum, coefficients, aggregate root, ApplyQC or current state.

## Formal boundary

Feature 008 refines the accepted ISC, seed, EC, APC, shard, aggregate, apply, durability, recovery and
current-pointer actions. It introduces no certificate type, parent edge, failure terminal, partial
apply outcome or alternative current transition. Discovery of one is `SEMANTIC` and returns the
branch to feature 000 before production implementation continues.
