# DeltaTorrent

DeltaTorrent — исследовательская система для обучения и дообучения языковых моделей на географически распределённой сети неоднородных GPU с ограниченной памятью и нестабильными WAN-соединениями.

Репозиторий находится на стадии **specification-first**: реализация ещё не начата. Spec Kit-артефакты разбиты на последовательные стековые feature-ветки. Каждая следующая ветка основана на предыдущей и добавляет одну независимо проверяемую возможность.

## Неподвижный архитектурный инвариант

Система разделяет два контура:

1. **Reduce plane** агрегирует разные локальные обновления работников в единую глобальную дельту.
2. **Distribution plane** распространяет уже агрегированный неизменяемый объект через content-addressed P2P-сеть.

Локальные обновления работников **не должны** рассылаться всем участникам torrent-подобным способом. P2P-раздача применяется к датасетам, checkpoint, базовым моделям и глобальным агрегированным дельтам.

## Порядок реализации

| Шаг | Feature-ветка | Результат |
| ---: | --- | --- |
| 1 | `001-reproducible-training-baseline` | Воспроизводимый single-node baseline и WAN-эмулятор |
| 2 | `002-local-round-engine` | Локальные AdamW-шаги и псевдоградиент |
| 3 | `003-central-round-coordinator` | Синхронные раунды, token-weighted reduce и outer optimizer |
| 4 | `004-compressed-delta-protocol` | INT8/FP16 codec, шардирование и error feedback |
| 5 | `005-content-addressed-p2p-distribution` | Проверяемая P2P-раздача агрегированных объектов |
| 6 | `006-regional-hierarchical-reduce` | Региональная и шардированная иерархическая редукция |
| 7 | `007-adaptive-heterogeneous-scheduling` | Адаптивные локальные раунды и bounded asynchrony |
| 8 | `008-permissioned-trust-and-resilience` | Подписанные обновления, screening и восстановление |
| 9 | `009-qlora-8gb-mode` | LoRA/QLoRA-режим для 8-гигабайтных GPU |
| 10 | `010-wan-benchmark-and-quality` | Token-matched WAN-бенчмарк и quality gates |
| 11 | `011-multiregion-pilot` | Пилот на 20–50 узлах и 3–5 регионах |

Полный набор спецификаций присутствует в последней стековой ветке `011-multiregion-pilot`. Карта зависимостей находится в `specs/ROADMAP.md`.

## Как выполнять очередной шаг

1. Переключиться на нужную feature-ветку.
2. Прочитать `.specify/memory/constitution.md`, затем `spec.md`, `plan.md` и `tasks.md` текущей функции.
3. Запустить cross-artifact анализ Spec Kit и устранить противоречия до изменения кода.
4. Реализовывать задачи строго по порядку, отмечая завершённые пункты в `tasks.md`.
5. Пройти exit gate функции и только после этого переходить к следующей ветке.

## Целевой MVP

Первый убедительный WAN-прототип должен поддерживать 20–50 удалённых GPU класса 8 ГБ, 3–5 регионов, полное обучение модели порядка 100–300 млн параметров либо QLoRA-режим, локальные раунды преимущественно по 128–512 шагов, INT8-сжатие с error feedback, региональное усреднение и P2P-раздачу глобальных дельт.

## Не входит в первичный MVP

Полностью permissionless-сеть, экономические стимулы, Sybil-resistance, полное предобучение плотной многомиллиардной модели на одном 8-гигабайтном GPU, WAN tensor/sequence parallelism и обязательная blockchain-инфраструктура отложены до получения воспроизводимого permissioned baseline.

Provenance и implementation-relevant сводка исходной концепции сохранены в `docs/source/deltatorrent-concept.ru.md`.
