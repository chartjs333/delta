# Checklist: 011 Hybrid Pilot

- [x] Pilot profile is selected by benchmark evidence, not operator preference.
- [x] Java, native and Python artifacts have separate identities/SBOMs.
- [x] Native durability recovers before network admission.
- [x] Embedded and sidecar crash semantics are not conflated.
- [x] Operators cannot bypass native consensus/current-state authority.
- [x] Runtime-specific faults, metrics and rollback are pilot gates.
- [x] GO binds the exact ABI/formal semantics/deployment profile.
